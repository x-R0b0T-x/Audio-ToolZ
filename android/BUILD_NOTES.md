# Notes du prototype Android

- Cible : ARM64, Android 10 minimum.
- Le script npm `tauri` est déclaré dans `package.json` pour permettre aux tâches Gradle générées de rappeler la CLI Tauri.
- La CLI est installée par le workflow GitHub Actions.
- Ce prototype ne constitue pas une publication Android officielle.
- La modification de ce fichier déclenche également la compilation de test sur `android-dev`.
